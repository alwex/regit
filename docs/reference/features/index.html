Features

A feature branch (feature-<name>) holds the work for a single feature. It is always created from the latest release tag, so each feature starts from the current stable line.

Start a feature

Fetches origin, then creates feature-<name> from the latest tag, adds a [regit] Init 'feature-<name>' commit and pushes the branch. If the branch already exists — locally, or only on origin (e.g. a teammate’s feature) — it is checked out instead.

The init commit is how tag list knows which features shipped in each version: start features with regit rather than git checkout -b.

Open a feature

If no feature name is provided, you will be prompted to start from an existing feature.

List features

Feature status

Run from a feature branch to show its details and where it branched from.

Based on an old release

If a feature was started from a tag older than the latest, feature start and feature status warn that the feature is based on an old release and print the command to catch it up:

Push a feature

Pushes the current feature branch to origin. Run it from a feature-* branch.

Remove a feature

Deletes the feature branch locally and on the remote. If you are currently on it, regit switches you back to stable first.
