Every finished release creates an annotated tag (`v<version>`). The tag command lets you
look back at what shipped in each version.

## List tags

```bash
regit tag list [-n <number>]
```

Lists the most recent tags and, for each one, the feature branches that were merged
between it and the previous tag — along with the tagger and date.

| Option | Default | Description |
| --- | --- | --- |
| `-n, --number <number>` | `5` | How many recent tags to list. |

```bash
# show the last 10 tags
regit tag list -n 10
```
